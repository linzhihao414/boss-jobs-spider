# BOSS直聘岗位采集工具

![Python](https://img.shields.io/badge/Python-3.8%2B-3776AB?logo=python&logoColor=white) ![DrissionPage](https://img.shields.io/badge/DrissionPage-Chromium%20automation-2EAD33) ![UI](https://img.shields.io/badge/UI-Tkinter-3776AB) ![License](https://img.shields.io/badge/License-MIT-green)

一个 BOSS直聘岗位数据采集工具，支持关键词搜索 + 城市定位，**图形界面一键操作**，自动采集岗位、公司简介、主营产品、工商注册信息（统一社会信用代码/法定代表人/注册资本/注册地址/经营范围）等完整数据。

## 快速开始

1. 安装 Python 3.8+（勾选 Add to PATH）
2. 双击 `run.bat`（自动安装依赖并启动图形界面）
3. 填好关键词 / 城市 / 数量 → 点「① 打开登录页」扫码登录
4. 登录完成后点「② 开始采集」
5. 完成后点「打开导出文件夹」查看 CSV

## 界面功能

- **图形界面**：直接填写关键词、城市、采集数量，无需改代码
- **一键操作**：打开登录页 → 扫码 → 开始采集 → 查看结果
- **设置自动保存**：上次填写的关键词/城市/数量自动记住
- **跨运行去重**：勾选后自动跳过已采集过的岗位，不重复
- **中途停止**：点「停止」当前页处理完即停，已采数据不丢失
- **每页自动保存**：中途关闭程序，已采集的数据也在「导出结果」里

## 采集字段（CSV 共 30+ 字段）

| 类别 | 字段 |
|------|------|
| 岗位信息 | 工作名称、工资、学历要求、工作经验要求、技术要求、工作介绍 |
| 地址信息 | 工作区域、工作详细地址、纬度、经度、位置标签 |
| 公司信息 | 公司、公司阶段、公司行业、公司规模、公司福利、公司主页、公司全称 |
| 业务信息 | 公司简介、主营产品、公司地址 |
| 工商注册 | 统一社会信用代码、法定代表人、注册资本、成立日期、注册地址、经营范围、经营状态 |
| 联系方式 | 联系方式（从岗位介绍/公司简介自动提取邮箱/电话/微信/QQ） |
| 其他 | 详情链接、encryptJobId |

## 配置说明

- **图形界面直接改**：关键词、城市（填名称如"广州"自动换算ID）、数量
- 配置保存在 `data/settings.json`，每次开始采集自动保存
- 也支持直接改 `config.txt`（keyword= / city=）

### 多关键词采集（重要）

关键词支持**逗号分隔填写多个**，例如：

```
keyword=皮具,女包,箱包
```

程序会对每个关键词**分别搜索采集**，结果自动合并去重：

- 岗位名只要包含**任意一个**关键词就保留（不管职位类型）
- 例：「皮具设计师」「女包主播」「箱包打版师」都会采集
- 「服装设计师」「主播」这类不含关键词的会过滤掉
- 采集数量 = 总量，程序自动分配给每个关键词（如填 300、3 个关键词 → 每个约 100 条）

### 采集数量说明

- 数量填大（如 100 / 300），程序会**自动翻页直到采满目标**（最多 100 页）
- 关键词太窄时（如"皮具设计"）每页匹配少，翻页会多一些，属正常
- 建议用**宽关键词**（如"皮具"）或多关键词，结果更多更准

## 目录结构

```
boss-jobs-spider/
├── boss_gui.py         # 图形界面主程序
├── boss_spider.py      # 采集引擎
├── run.bat             # 一键启动（自动装依赖）
├── config.txt          # 配置文件
├── data/settings.json  # 界面设置（自动保存）
├── 导出结果/boss_jobs.csv   # 采集结果（CSV）
├── browser_profile/    # 登录态目录（自动创建，扫码一次免登录）
└── README.md
```

## 环境要求

- Python 3.8+
- Windows 10/11
- Chrome 浏览器（自动检测路径）

## 安装依赖

```bash
pip install -r requirements.txt
```

主要依赖：DrissionPage（浏览器自动化）、requests

## 注意事项

1. 首次使用需扫码登录 BOSS直聘，登录态保存在 `browser_profile/`，后续免登录
2. 建议合理设置采集数量，避免触发风控
3. 若被风控（滑块/验证），请稍等几分钟再运行
4. 仅供学习研究使用，请遵守平台服务条款
